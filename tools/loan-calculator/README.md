# Loan Calculator — V30

La calculatrice reste dans `tools/loan-calculator/`. Ne placez pas ses fichiers à la racine.
Le guide intégré remplace l’ancienne rubrique « Comment fonctionne ce calcul ».
Il est placé après les résultats, avant le pied de page, dans un seul panneau dépliable.
Il suit les onze langues du site et conserve les explications du mode sélectionné.
Les exemples : deux prêts à taux nul avec mensualités par périodes ; apport affecté
au taux mensuel équivalent le plus élevé. En cas d’égalité ou de taux inconnu,
l’ordre de saisie s’applique. Cette priorité ne garantit pas le minimum absolu
de mensualité pour toutes les combinaisons de durées.
Les calculs et exports PDF/Excel sont inchangés. Aucune nouvelle dépendance.
Pour tester localement, servez la racine avec un serveur HTTP statique,
puis ouvrez `/tools/loan-calculator/`.
