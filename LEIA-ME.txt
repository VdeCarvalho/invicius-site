INVICIUS V24 — SITE COMPLETO

Este pacote contem TODOS os arquivos rastreados no repositorio, com a pagina inicial restaurada e a calculadora atualizada.

COMO ENVIAR
1. Descompacte o ZIP.
2. Abra a RAIZ do repositorio invicius-site no GitHub.
3. Add file > Upload files.
4. Selecione os arquivos e pastas que estao DIRETAMENTE dentro do ZIP. Arraste tools como PASTA INTEIRA, assets como PASTA INTEIRA, scripts como PASTA INTEIRA e .github como PASTA INTEIRA.
5. Nao abra tools para selecionar seus arquivos individualmente. Nao misture os arquivos das subpastas com os da raiz.
6. Confira na lista de upload: index.html e tools/loan-calculator/index.html precisam aparecer como DOIS caminhos diferentes.
7. Confirme o commit e aguarde o deploy.

O index.html DA RAIZ deve ter titulo Invicius.
O index.html DA CALCULADORA deve estar em tools/loan-calculator/index.html e ter titulo Loan Calculator.

Os arquivos com nomes numerados ja presentes no repositorio foram preservados neste pacote completo.
