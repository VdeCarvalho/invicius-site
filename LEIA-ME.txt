1. Ouvrez VdeCarvalho/invicius-site, branche main.
2. SUPPRIMEZ les fichiers anciens listés ci-dessous.
   Chaque fichier : ouvrir > menu ... > Delete file > Commit changes sur main.
   Ou ouvrez l'éditeur GitHub en appuyant sur la touche . depuis le dépôt.
   Dans son explorateur : clic droit sur chaque fichier de la liste > Delete.
   Dans Source Control : vérifiez la liste, saisissez un message, Commit & Push.
3. Décompressez ce ZIP et envoyez TOUT son contenu à la RACINE du dépôt
   avec Add file > Upload files, puis Commit changes sur main.
   Conservez les dossiers assets, tools, scripts et .github.
   Sur Windows, vérifiez que le dossier .github est bien inclus.
   N'envoyez pas le ZIP lui-même, ni une enveloppe de dossier supplémentaire.
4. Settings > Pages > Source : GitHub Actions.
5. Attendez le succès de la dernière publication dans Actions.
